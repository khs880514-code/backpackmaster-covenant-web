# 급소 타격 시뮬레이터 — 상세 모델링 지시서 (v1)

대상: 이 문서를 보고 상세 모델(3D/2D)을 직접 만들어 연결할 사람.
기준 파일: `index.html` (한 파일, three.js r128, 브라우저에서 바로 열림)

---

## 0. 목적과 톤

- 목적: 호신술 수업에서 "패드만 치면 모르는 것"을 보여주기. **실제 급소에 맞으면 조직에서 어떤 일이 생기는지, 힘·횟수·시간·신발·타격 종류에 따라 위험이 어떻게 달라지는지**를 설명한다.
- 톤: 해부학 교육 자료 수준. 노골적·잔혹한 표현(피 튀김, 찢어진 살 등) 금지. 모식도(단면도) 스타일 유지. 위험 구간은 "파열 위험 부위" 같은 표시와 글로 설명.
- 반드시 같이 보여줄 것: (1) 사고 예방(보호컵·패드·힘 통제) (2) 사고 시 대응(병원 가야 하는 신호). 이미 `index.html`에 들어 있음.
- 모든 숫자는 "교육용 추정치"로 표시. 진단·치료 기준처럼 보이면 안 됨. **의료 전문가 검토 전에는 외부 배포 금지.**

## 1. 현재 구현 상태 (`index.html`)

| 영역 | 상태 |
|---|---|
| 입력 | 상황 5개, 신발 4종, 타격 7종(운동화/하이힐/플랫폼/부츠/무릎/손 쳐올리기/쥐기), 힘 1~11, 연속 횟수 1~6, 쥐는 시간 1~10초 |
| 힘 계산 | `physics()` : F = m·v / t (유효질량·속도·접촉시간), 전달력 Ft = F × 전달률 |
| 접촉 면적 | `AREA` 표 (신발·방향별). 작은 면적 → 같은 힘이라도 위험 ↑ (`FtAdj`) |
| 누적 | `applyLoad()` : 타격 1회 = (FtAdj/450)^1.5, 횟수만큼 합산. 쥐기 = (Ft/250)^1.5 × 시간/4 |
| 단계 | 누적값 → 5단계 (0.05 / 0.25 / 1.0 / 2.0 경계) |
| 상세 창 | 🔬 버튼 → 2D 단면 모식도 + 위험 7항목 표 + 보호컵 비교. 입력이 바뀌면 자동 갱신 |
| 3D 장면 | 관절 인형 + 급소 확대 투시 창. 단계에 따라 색·붓기·치한 반응이 바뀜 |

핵심 상태 객체: `S`(UI 상태), `P`(계산 결과: `Ft, FtAdj, area, press, load, stageIdx, stage, sev, squash`).
**새 모델은 `P`만 읽으면 모든 입력과 자동 연동된다.** 입력 로직은 건드리지 않는 것을 원칙으로 한다.

## 2. 이번에 만들어 줄 것 (우선순위)

### A. 해부 모델 (3D 또는 2D 레이어 에셋)
레이어(바깥 → 안). 각 레이어는 개별 메쉬/스프라이트 + 개별 재질(색·투명도)로 분리해야 단계별 변화를 줄 수 있음.

1. 피부 + 음낭근막(dartos)
2. 고환초막(tunica vaginalis) — 얇은 액체층이 있는 이중 막
3. 백막(tunica albuginea) — 하얗고 질긴 막. **파열 표시가 걸리는 핵심 레이어**
4. 고환 실질(parenchyma)
5. 부고환 — 고환 뒤쪽 초승달 모양
6. 정삭 — 혈관·정관 다발. 위로 올라가 치골 아래로. **염전 시 꼬이는 부분**
7. 치골 결합부 — 단단한 뼈. **타격 시 고환이 눌려 끼이는 받침대**

필요한 변형(모프 타깃 / 쉐이더 파라미터):

| 변형 | 파라미터 | 설명 |
|---|---|---|
| 압착 | `compress` 0~1 | 치골과 타격면 사이에서 납작해짐. 폭 +, 높이 − |
| 되튐 진동 | `ringdown` | 압착 후 1~2회 감쇠 진동 |
| 부종 | `swell` 0~1 | 시간 경과 후 전체 부풂 |
| 혈종 | `hematoma` 0~1 | 초막과 백막 사이를 어두운 붉은색으로 채움 |
| 멍 | `bruise` 0~1 | 피부·조직 색이 붉음 → 보라 → 검붉음 |
| 정삭 꼬임 | `twist` 0~1 | 정삭이 나선으로 감김 (염전 표시) |
| 파열 표시 | `rupture` 0~1 | 백막에 **점선 + 라벨**. 단면이 벌어지는 사실적 묘사는 하지 않음 |

### B. 타격체 모델 (타격 종류·신발 연동)
접촉 면적과 모양이 위험을 바꾼다는 걸 눈으로 보여줄 것.

| 타격체 | 접촉 모양 | 면적(m²) 현재 값 |
|---|---|---|
| 운동화 올려차기(발등) | 넓고 평평 | 0.0030 |
| 운동화 앞차기(앞꿈치) | 중간 | 0.0015 |
| 하이힐 올려차기 | 중간 | 0.0025 |
| 하이힐 앞차기(뾰족 앞코) | **좁음** | 0.0006 |
| 플랫폼힐 | 넓음 | 0.0030 / 0.0015 |
| 롱부츠 | 넓고 단단 | 0.0035 / 0.0020 |
| 무릎 | 둥글고 단단 | 0.0040 |
| 손 쳐올리기 | 평평 | 0.0020 |
| 쥐기 | 양쪽에서 감싸 압박 + 비틀기 | (면적 대신 시간) |

→ 각 타격체의 3D 모델에 **압력 히트맵(접촉점이 붉게 번지는 효과)** 을 얹을 수 있게 UV/접촉점 위치를 잡아 둔다.

### C. 시간 경과 애니메이션 (6단계 키프레임)
상세 창의 슬라이더와 동일: 타격 전 / 접촉 / 최대 눌림 / 되튐 / 수 분 뒤 / 수 시간 뒤.
각 키프레임에서 위 변형 파라미터 값을 단계(stageIdx)별로 가져와 보간한다.

## 3. 변형 파라미터 표 (단계 × 시간)

`stageIdx`: 0 경미, 1 강한 통증, 2 행동불능 가능, 3 부상 위험, 4 중대한 부상(누적)

| 파라미터 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| `swell` (수 시간 뒤 최대) | 0.04 | 0.08 | 0.16 | 0.28 | 0.50 |
| `hematoma` | 0 | 0 | 0.15 | 0.50 | 0.90 |
| `bruise` 색 | #d98a95 | #d9707a | #a85a78 | #7a3f66 | #4a2a52 |
| `twist` | 0 | 0 | 0 | 위험도 표 따름 | 위험도 표 따름 |
| `rupture` 라벨 | 없음 | 없음 | 없음 | 위험 "가능" 이상일 때 | 위험 "가능" 이상일 때 |

(현재 `STAGE_SWELL`, `STAGE_COLOR` 값. 에셋에 맞게 조정 가능하지만 **단계 순서와 단조 증가는 유지**.)

시간 계수(`tf`): 타격 전·접촉·최대 눌림·되튐 = 0, 수 분 뒤 = 0.5, 수 시간 뒤 = 1.

## 4. 위험도 표 (상세 창 오른쪽) — 입력과 임계값

`E` = 누적을 반영한 "등가 단일 타격 힘(N)" = `450 × load^(2/3)` (보호컵 가정 시 ×0.15).
등급: `E < t1` 거의 없음 / `t1~t2` 낮음 / `t2~t3` 가능 / `t3 이상` 높음.

| 항목 | t1 | t2 | t3 | 비고 |
|---|---|---|---|---|
| 일시적 통증·숨 막힘·메스꺼움 | 30 | 100 | 250 | 미주신경 반사 |
| 피부·음낭 멍과 붓기 | 70 | 180 | 350 | |
| 부고환·정삭 타박 | 120 | 250 | 450 | 며칠~몇 주 통증 |
| 음낭 안 출혈(혈종) | 200 | 350 | 550 | |
| 고환 백막 파열 | 350 | 450 | 650 | **450N ≈ 46kgf. 문헌상 약 50kgf 부근부터 보고** (정확한 출처 확인 필요) |
| 외상성 염전 | 250 | 450 | 700 | **쥐기+비틀기는 임계값을 낮춤**: ×(0.55 + 0.05×쥐는 초, 최대 8초) |
| 장기 후유증 | 450 | 600 | 900 | |

⚠ 이 임계값은 **현재 개발자가 정한 추정치**다. 실제 문헌과 대조해 고쳐야 한다 (6장).

## 5. 연동 규칙 (반드시 지킬 것)

1. 새 시각화는 `P`(및 `S`)만 읽는다. 별도 입력 UI를 만들지 않는다.
2. 같은 입력이면 **3D 장면 단계 = 상세 창 단계 = 위험도 표**가 일치해야 한다. (보호컵 가정 때만 상세 창이 다름 — 칩에 "보호컵 착용" 표시)
3. 힘·횟수·시간·신발·타격 종류 중 하나만 바꿔도 변화가 보여야 한다. 아래 6장 테스트로 확인.
4. 누적이 쌓이면 단계가 **내려가지 않는다** (회복 모델은 v2).

## 6. 검증 케이스 (수동 확인)

| # | 설정 | 기대 결과 |
|---|---|---|
| 1 | 운동화 올려차기, 힘 3, 1회 | 경미~강한 통증. 파열·염전 "거의 없음" |
| 2 | 운동화 올려차기, 힘 6, 1회 | 강한 통증~행동불능. 혈종 "낮음 이하" |
| 3 | 운동화 올려차기, 힘 11, 4회 | 중대한 부상(누적). 혈종·파열 "가능" 이상 |
| 4 | 같은 힘 6, **하이힐 앞차기** vs 운동화 올려차기 | 하이힐 쪽 접촉 압력이 훨씬 높고 단계가 같거나 높음 |
| 5 | 쥐기, 힘 11, 3초 vs 8초 | 8초에서 "중대한 부상" + 염전 등급 상승 |
| 6 | 3번 설정 + 보호컵 체크 | 등급이 크게 내려감 (보호 효과 교육용) |
| 7 | 슬라이더 "수 시간 뒤" | 단계가 높을수록 붓기·혈종·색이 뚜렷 |

## 7. 의료 검토 요청 사항 (전문가에게 보낼 질문)

1. 4장 임계값(N)이 문헌과 맞는가? 특히 백막 파열·염전·혈종.
2. 접촉 면적이 좁을 때 위험 증가 보정 `(0.003/area)^0.25` (0.85~1.45 제한)이 타당한가?
3. 쥐고 비틀기의 시간·염전 관계를 어떻게 표현해야 안전하고 정확한가?
4. 연속 타격의 누적 방식(단순 합산)이 적절한가? 회복 시간을 넣어야 하는가?
5. "병원 가야 하는 신호"·"6시간" 표현이 일반 수강생에게 안전한가?
6. 보호컵 감소율(×0.15)은 어느 정도가 현실적인가?

## 8. 산출물 형식

- 3D: glTF 2.0 (`.glb`), 총 5MB 이하 권장. 레이어별 노드 이름 고정: `skin`, `tunica_vaginalis`, `albuginea`, `parenchyma`, `epididymis`, `cord`, `pubic_bone`. 모프 타깃 이름: `compress`, `swell`, `hematoma`, `twist`.
- 2D 대안: 레이어별 SVG (같은 이름의 `<g id>`), 변형은 CSS 변수 또는 JS 변환.
- 인체(두 사람 장면): 리깅된 glTF 인체 + 현재 키프레임(`TRACKS`)에서 관절 목표점을 뽑아 IK로 연결. 저작권이 확실한 모델(CC0 또는 직접 제작)만 사용.
- 연결 지점: `drawDetail()`(2D 상세 창)과 `applyPose()`(3D 장면). 새 모델을 붙일 때 이 두 함수 안의 `STAGE_*` 상수와 `P`만 사용.
